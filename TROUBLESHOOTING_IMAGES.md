# Решение проблем с загрузкой изображений

## 🔍 Диагностика проблемы

### Шаг 1: Проверьте консоль браузера
1. Откройте приложение в браузере
2. Нажмите F12 (или ПКМ → Inspect)
3. Перейдите на вкладку **Console**
4. Обновите страницу

Вы должны увидеть сообщения вида:
- `Попытка загрузить изображение для стиля "High Heels": /images/styles/high-heels.jpg`
- `Не удалось загрузить изображение...` (если файл не найден)

### Шаг 2: Проверьте вкладку Network
1. В DevTools перейдите на вкладку **Network**
2. Обновите страницу
3. Отфильтруйте по "Img"
4. Найдите запросы к `/images/styles/` или `/images/teachers/`

Если видите ошибку **404 (Not Found)** - файл не существует по указанному пути.

## ✅ Решение

### Вариант 1: Добавьте изображения вручную

1. **Для стилей танцев:**
   - Откройте папку: `public/images/styles/`
   - Добавьте файлы с именами:
     - `high-heels.jpg` (для стиля "High Heels")
     - `hip-hop.jpg` (для стиля "Hip-Hop")
     - `twerk.jpg` (для стиля "Twerk")
     - `contemporary.jpg` (для стиля "Contemporary")
     - `breaking.jpg` (для стиля "Breaking")
     - `jazz-funk.jpg` (для стиля "Jazz Funk")
     - `vogue.jpg` (для стиля "Vogue")

2. **Для преподавателей:**
   - Откройте папку: `public/images/teachers/`
   - Добавьте файлы с именами:
     - `vano.jpg`
     - `alex.jpg`
     - `maya.jpg`
     - `kate.jpg`
     - `max.jpg`
     - `liza.jpg`
     - `diana.jpg`
     - `nikita.jpg`

### Вариант 2: Используйте тестовые изображения

Для быстрого тестирования можно использовать placeholder изображения:

1. Скачайте любое изображение (например, с https://placeholder.com)
2. Сохраните его в нужную папку с правильным именем
3. Перезапустите сервер разработки (`npm start`)

## 🔧 Важные моменты

1. **Имена файлов должны быть в нижнем регистре:**
   - ✅ `high-heels.jpg`
   - ❌ `High-Heels.jpg`
   - ❌ `high_heels.jpg`

2. **Используйте дефисы вместо пробелов:**
   - ✅ `hip-hop.jpg`
   - ❌ `hip hop.jpg`

3. **Поддерживаемые форматы:**
   - `.jpg` / `.jpeg`
   - `.png`
   - `.webp`

4. **После добавления файлов:**
   - Перезапустите сервер разработки (`npm start`)
   - Очистите кеш браузера (Ctrl+Shift+R)

## 🧪 Быстрый тест

Чтобы проверить, что система работает:

1. Создайте файл `public/images/styles/test.jpg` (любое изображение)
2. Временно измените название одного стиля в `db.json` на "Test"
3. Обновите страницу - изображение должно загрузиться

## 🐛 Если проблема сохраняется

1. Проверьте, что файлы действительно находятся в папке `public/images/`
2. Убедитесь, что сервер разработки запущен
3. Проверьте консоль браузера на ошибки
4. Попробуйте открыть изображение напрямую в браузере: `http://localhost:3000/images/styles/high-heels.jpg`

Если изображение открывается напрямую, но не загружается в компоненте - проблема в коде.
Если изображение не открывается напрямую - проблема в пути или файле.
