# Dance Room - Студия современных танцев

Веб-приложение для студии современных танцев с возможностью просмотра стилей, записи на занятия и управления профилем.

## 🚀 Технологический стек

- **React 18** - UI библиотека
- **React Router** - маршрутизация
- **React Query** - управление серверным состоянием
- **JSON Server** - mock API
- **Swiper** - слайдеры

## 📁 Архитектура проекта

Проект использует **Feature-Sliced Design (FSD)** архитектуру.

### Структура проекта

```
src/
├── app/                    # Инициализация приложения
│   ├── providers/          # Провайдеры (Router, Query, Auth)
│   ├── styles/            # Глобальные стили
│   └── index.jsx          # Композиция App
│
├── pages/                  # Страницы (роуты)
│   ├── home/
│   ├── about/
│   ├── login/
│   ├── registration/
│   ├── profile/
│   └── schedule/
│
├── features/               # Бизнес-фичи (действия пользователя)
│   ├── auth/              # Авторизация
│   ├── book-class/        # Бронирование занятия
│   ├── leave-review/      # Создание отзыва
│   └── filter-schedule/   # Фильтрация расписания
│
├── entities/               # Бизнес-сущности
│   ├── user/
│   ├── teacher/
│   ├── dance-style/
│   ├── booking/
│   ├── review/
│   └── schedule-class/
│
└── shared/                 # Переиспользуемый код
    ├── ui/                # UI Kit
    ├── lib/               # Обертки библиотек
    ├── api/               # Базовая конфигурация API
    └── utils/             # Утилиты
```

### Правила импортов

- `app` → может импортировать из всех слоёв
- `pages` → может импортировать из `features`, `entities`, `shared`
- `features` → может импортировать из `entities`, `shared`
- `entities` → может импортировать из `shared`
- `shared` → не импортирует из других слоёв

## 🛠️ Установка и запуск

### Установка зависимостей

```bash
npm install
```

### Запуск приложения

```bash
# Запуск React приложения
npm start

# Запуск JSON Server (в отдельном терминале)
npm run server
```

Приложение будет доступно по адресу: `http://localhost:3000`  
API сервер: `http://localhost:3001`

## 📚 Структура фичи/сущности

Каждая фича и сущность организована следующим образом:

```
feature-name/
├── ui/              # UI компоненты
├── model/           # Бизнес-логика, хуки
├── api/             # API запросы (если нужны)
└── index.js         # Public API (экспорты)
```

## 🔧 Разработка

### Добавление новой фичи

1. Создайте папку в `src/features/`
2. Организуйте по структуре: `ui/`, `model/`, `api/`
3. Экспортируйте через `index.js`
4. Используйте в страницах через импорт из фичи

### Добавление новой сущности

1. Создайте папку в `src/entities/`
2. Организуйте по структуре: `ui/`, `model/`, `api/`
3. Экспортируйте через `index.js`
4. Используйте в фичах и страницах
