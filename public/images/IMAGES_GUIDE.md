# Руководство по добавлению изображений

## 📁 Структура папок

```
public/images/
├── styles/          # Изображения стилей танцев
└── teachers/       # Фотографии преподавателей
```

## 🎨 Изображения стилей танцев

Добавьте изображения в папку `public/images/styles/` со следующими именами:

| Стиль | Имя файла | Пример |
|-------|-----------|--------|
| High Heels | `high-heels.jpg` | Изображение танца на каблуках |
| Hip-Hop | `hip-hop.jpg` | Изображение хип-хоп танца |
| Twerk | `twerk.jpg` | Изображение твёрка |
| Contemporary | `contemporary.jpg` | Изображение современного танца |
| Breaking | `breaking.jpg` | Изображение брейк-данса |
| Jazz Funk | `jazz-funk.jpg` | Изображение джаз-фанка |
| Vogue | `vogue.jpg` | Изображение вога |

**Требования:**
- Формат: JPG, PNG или WebP
- Размер: минимум 800x600px (рекомендуется 1200x800px)
- Соотношение сторон: 4:3 или 16:9

## 👨‍🏫 Фотографии преподавателей

Добавьте фотографии в папку `public/images/teachers/` со следующими именами:

| Преподаватель | Имя файла | Пример |
|---------------|-----------|--------|
| Vano | `vano.jpg` | Фото преподавателя Vano |
| Alex | `alex.jpg` | Фото преподавателя Alex |
| Maya | `maya.jpg` | Фото преподавателя Maya |
| Kate | `kate.jpg` | Фото преподавателя Kate |
| Max | `max.jpg` | Фото преподавателя Max |
| Liza | `liza.jpg` | Фото преподавателя Liza |
| Diana | `diana.jpg` | Фото преподавателя Diana |
| Nikita | `nikita.jpg` | Фото преподавателя Nikita |

**Требования:**
- Формат: JPG, PNG или WebP
- Размер: минимум 400x400px (рекомендуется 600x600px)
- Соотношение сторон: квадратное (1:1)
- Стиль: портретное фото, профессиональное качество

## 🔄 Как это работает

1. Компоненты автоматически ищут изображения по имени файла
2. Если изображение не найдено, используется fallback:
   - Для стилей: цветной фон с названием стиля
   - Для преподавателей: placeholder изображение
3. Поддерживаются форматы: `.jpg`, `.jpeg`, `.png`, `.webp`

## 📝 Примеры имен файлов

**Стили:**
- `high-heels.jpg` ✅
- `hip-hop.png` ✅
- `twerk.webp` ✅
- `High Heels.jpg` ❌ (неправильно - используйте нижний регистр и дефисы)

**Преподаватели:**
- `vano.jpg` ✅
- `alex.png` ✅
- `Vano.jpg` ❌ (неправильно - используйте нижний регистр)

## ⚠️ Важно

- Имена файлов должны быть в нижнем регистре
- Используйте дефисы вместо пробелов
- Расширение файла может быть `.jpg`, `.jpeg`, `.png` или `.webp`
- Изображения должны быть оптимизированы для веба (сжаты)
