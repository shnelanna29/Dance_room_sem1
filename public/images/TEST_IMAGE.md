# Тестовая инструкция для проверки изображений

## Как проверить, что изображения загружаются:

1. **Откройте консоль браузера** (F12 → Console)

2. **Добавьте тестовое изображение:**
   - Создайте файл `public/images/styles/test.jpg` (любое изображение)
   - Или добавьте реальное изображение для одного из стилей, например `high-heels.jpg`

3. **Проверьте в консоли:**
   - Должны появиться сообщения о попытке загрузки изображений
   - Если изображение найдено - будет сообщение об успешной загрузке
   - Если не найдено - будет предупреждение

4. **Проверьте путь:**
   - В консоли будет показан полный путь, по которому ищется изображение
   - Убедитесь, что файл находится именно по этому пути

## Примеры правильных путей:

- Для стиля "High Heels": `/images/styles/high-heels.jpg`
- Для преподавателя "Vano": `/images/teachers/vano.jpg`

## Если изображения не загружаются:

1. Проверьте, что файлы находятся в правильной папке
2. Проверьте имя файла (должно быть в нижнем регистре, с дефисами вместо пробелов)
3. Проверьте расширение файла (.jpg, .png, .webp)
4. Убедитесь, что сервер разработки перезапущен после добавления файлов
5. Проверьте консоль браузера на ошибки 404
